# ADR 0003: Product name

Status: accepted 2026-09-26.

The product is called **Overheard AI**. The README and the package metadata describe it as an
"AI visibility tracker", because that is the term people search for.

Names in the code use the stem `overheard`: the package `overheard-ai`, the `OVERHEARD_*`
environment variables, the default database file `./data/overheard.db`, the `overheard:` keys
the browser stores, and the `overheard.` keys on the process.

`overheard.ai` is not the product's address and is not published as one.
